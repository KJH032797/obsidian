## 1. 각 파트의 역할


① PM / Integrator — 프로젝트 관리·통합

전체 진행 관리

- 프로젝트 폴더, 공통 설정, 개발 환경 구성
    
- 팀원별 작업 범위와 일정 조율
    
- 각자 만든 코드를 통합하고 실행 여부 확인
    
- Git 브랜치, Pull Request, Merge 관리
    
- 전체 프로젝트 흐름과 완료 기준 관리
    

핵심 파일 예시: `README.md`, `requirements.txt`, `.gitignore`, 공통 설정



② Data / QA — 데이터 분석·구성

학습 데이터 준비

- 교과 7에서 넘겨받은 이미지와 TXT의 수량·짝 확인
    
- Class별 객체 수와 장면 유형 분포 분석
    
- 유사 이미지와 촬영 그룹을 확인해 Data Leakage 방지
    
- Train / Validation / Frozen Test / Bridge Holdout 분할
    
- YOLO용 폴더 및 `dataset.yaml` 구성
    

모델이 공부할 자료와 시험에 사용할 자료를 올바르게 준비하는 역할

핵심 파일 예시: `dataset_audit.py`, `split_builder.py`, `split_manifest.csv`, `dataset_summary.csv`, `split_policy.md`



③ Training — 모델 학습

Baseline 생성

- 작은 데이터로 Smoke Test 실행
    
- YOLO11n으로 Baseline Model 학습
    
- 학습 조건과 실행 결과 기록
    
- `best.pt`, `results.csv`, 학습 그래프 보존
    

준비된 정답 데이터를 이용해 AI가 이물질의 종류와 위치를 학습하도록 만드는 역할

핵심 파일 예시: `train_detector.py`, `06_train_baseline.py`, `baseline_best.pt`



④ Evaluation / Failure — 성능 평가·실패 분석

모델의 문제 파악

- Validation 데이터로 Precision, Recall, mAP 측정
    
- Class별 성능 확인
    
- 이물이 없는데 검출한 FP, 이물을 놓친 FN 조사
    
- Class 오류와 BBox 위치 오류 사례 확인
    
- 실제 실패 이미지와 분석 결과 기록
    

모델이 얼마나 잘하는지 측정하고, 무엇을 왜 틀리는지 찾아내는 역할

핵심 파일 예시: `evaluate_detector.py`, `failure_analyzer.py`, `baseline_metrics.csv`, `failure_analysis.csv`



⑤ Experiment — 모델 개선 실험

개선 효과 검증

- 실패 분석 결과에서 개선할 문제 하나를 선정
    
- 이미지 입력 크기, Augmentation 등 주요 변수 하나 변경
    
- Improved Model 재학습
    
- 같은 Validation에서 Baseline과 결과 비교
    
- 실험 조건과 개선 효과를 문서화
    

모델을 무작정 여러 번 학습하는 게 아니라, 한 가지 조건을 바꿨을 때 실제로 좋아지는지 확인하는 역할

핵심 파일 예시: `experiment_runner.py`, `improvement_experiment.md`, `experiment_log.csv`, `baseline_vs_improved.md`



⑥ Inference / Document — 모델 활용·문서화·인계

최종 결과물 완성

- 최종 모델을 새로운 이미지에 적용해 Detection
    
- BBox, Class, Confidence가 표시된 결과 저장
    
- Auto Label로 YOLO TXT 후보 생성
    
- 교과 7 라벨링 도구에서 사람이 검수하는 과정 연결
    
- README, 인수인계 문서, 시연 자료 정리
    

학습된 AI가 실제로 작동하는 것을 보여주고, 다른 사람이 실행하고 활용할 수 있도록 마무리하는 역할
