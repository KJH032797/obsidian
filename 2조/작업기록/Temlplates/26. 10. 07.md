# 작업 기록 (2026-10-07)

> [!info] 오늘 한 줄 요약
> 1. Manifest 경로를 이물검출_학습데이터1·2/... 기준으로 통일
> 2. BBox·Class 개수 변화를 보여주는 컬럼 추가 (bbox_diff, class_diff 등)
> 3. 저장 폴더에 labels가 두 번 겹치던 문제 해결

## 1. 변경 이유

> [!question] 왜 바꿨나
> - csv에서 각 데이터의 원본 출처가 데이터 1인지 2인지 미표기, **정보를 알 수 없음**
> - 원본 라벨링 데이터와 작업자의 수정 이후 데이터의 변화를 알 수 있는 정보의 추가
> - 라벨링 작업 후에 라벨링 데이터가 저장되는 경로의 자동생성에서 labels 폴더가 두 번 중복되어 **파일 구조가 원본과 통일되지 않음**

> [!success] 목표
> - **원본 데이터 출처 표기**: csv의 path 컬럼에서 경로의 최상단이 데이터 1인지 2인지까지 표기
> - **원본과 라벨링 이후 BBox와 Class 수와 차이 표기**: 데이터 정보를 더 알 수 있는 컬럼을 추가
> - **경로 자동 생성하는 코드를 확인하고 수정**: 중복을 만들게 하는 코드를 확인하고 수정

## 2. 변경 파일

| 구분  | 파일                              | 역할                                 |
| --- | ------------------------------- | ---------------------------------- |
| 수정  | `src/manifest.py`               | Manifest CSV의 컬럼 및 데이터 관리          |
| 수정  | `src/manifest_builder.py`       | RAW 데이터를 기반으로 Manifest 생성·통계 정보 추가 |
| 수정  | `src/yolo/dataset.py`           | RAW/WORK 이미지·라벨 경로 관리 및 데이터 스캔     |
| 수정  | `src/bbox/session.py`           | BBox 편집 결과를 Manifest와 WORK에 저장     |
| 수정  | `scripts/04_merge.py`           | 작업자별 WORK 라벨을 하나의 결과물로 병합          |
| 수정  | `scripts/10_export_manifest.py` | Manifest 데이터를 최종 CSV로 내보내기         |

## 3. 기능 개선 전/후

| 구분             | 변경 전                                      | 변경 후                                                      |
| -------------- | ----------------------------------------- | --------------------------------------------------------- |
| Manifest 통계    | BBox 개수만 기록                               | BBox 개수 + Class 종류 수 기록                                   |
| Manifest 차이값   | BBox 차이만 관리                               | BBox 차이 + Class 차이 관리                                     |
| 기존 Manifest    | 기존 행의 누락된 통계 보완 안 됨                       | 프로그램 실행 시 누락된 통계 자동 보완                                    |
| 원본 경로          | 데이터셋 이름 없이 `images/...`, `labels/...` 형태  | `이물검출_학습데이터N/images/...`, `이물검출_학습데이터N/labels/...` 형태로 관리 |
| 데이터셋 구분        | `source_dataset`이 실제 데이터셋과 다르게 기록될 수 있음   | `이물검출_학습데이터1`, `이물검출_학습데이터2` 등 실제 데이터셋명 기록                |
| WORK 저장 경로     | RAW 구조와 WORK 구조가 맞지 않음                    | `WORK/이물검출_학습데이터N/labels/...`로 RAW와 동일한 구조 유지             |
| Manifest 경로 보정 | 기존 Manifest의 경로가 변경된 구조와 맞지 않을 수 있음       | 기존 Manifest 경로를 새 데이터셋 경로 구조로 자동 보정                       |
| 작업자 라벨 병합      | `label_relative_path`와 실제 WORK 경로 연결이 불명확 | Manifest의 `label_relative_path` 기준으로 작업자 라벨을 찾아 병합        |
| 최종 Manifest    | 기존 통계 컬럼만 내보냄                             | 새 BBox·Class 통계 및 차이값까지 함께 내보냄                            |
